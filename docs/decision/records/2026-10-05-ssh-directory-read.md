# SSH の側でディレクトリが空のファイルとして読める不具合を直す判断

## Context

SSH の一件ずつの読み込みは `openssl base64 -in` を使うが、openssl はディレクトリを読むと "Is a directory" を出しながら終了コード 0 で空を返す。
このため SSH の側だけディレクトリやディレクトリへの symlink が空のファイルとして読め、diff の結果がローカルやエージェントの側と食い違っていた。
読み込みを直すと、diff が中身の空なディレクトリと include の外のディレクトリをどう示すかが読み込みの成否に頼れなくなる。
そこで diff がディレクトリを子の一覧の取得で判定する形に変え、その振る舞いと、この不具合を原因とする問題記録の扱いを決める。
子の一覧の取得が利用者の入力したパスをそのまま読むことになるため、ローカルの子の一覧の取得は絶対パスや `..` で root_dir の外へ出るパスを拒み、root_dir の外のディレクトリを一覧しない。

## Agreements

- A1 include の外のディレクトリが左右の両方にあり、それを指定した diff は、配下を include で絞った結果に比べるファイルがないものとして、差分なし（"0 file(s) with changes"）・終了コード 0 にする。ローカル・SSH・エージェントのどの経路の組でも、指定したパスの数によらず同じにする。片側にだけあるディレクトリはこの決定の対象にしない（[FLAG-cli-073](../../ir/cli/FLAGS.md#FLAG-cli-073) に残す）。[REQ-cli-077](../../ir/cli/directory-paths.md#REQ-cli-077) として書く。
  - why: 利用者の決定の理由は記録されていない。AI が確かめたところ、この答えは include を比べる対象を一致するパスに限る設定とする [REQ-config-004](../../ir/config/filters.md#REQ-config-004) と、中身の空なディレクトリを差分なしとする [REQ-cli-025](../../ir/cli/directory-paths.md#REQ-cli-025) の既存のテストと矛盾しない。
  - decided_by: 利用者（2026-10-05）。左右の両方にある場合に限る絞り込みも利用者が 2026-10-05 に決めた
- A2 FLAG-cli-045 を閉じる。左がローカルの通常ファイル、右が SSH のディレクトリ symlink の組でも、diff は右の配下を入口からの子パスで示す。IR は変えない。
  - why: コードが両方の向きで [REQ-cli-021](../../ir/cli/symlink-diff.md#REQ-cli-021) を満たすようになった。この向きでは右の子のパスを左で調べるとき、ローカルのパスの検査が途中が通常ファイルのパスを "Not a directory" のエラーにして比較全体が止まっていた。diff がディレクトリを子のパスに展開するとき、子の一覧が取れなかった側（通常ファイル・参照先のない symlink・読めない参照先）にはその子がないものとし、その側の子のパスを調べも読みもしないようにした。エラーの種類や文言には頼らないので、経路によらず同じに働く。rollback・バックアップ・書き込みも使うローカルとエージェントの共有のパスの検査は変えていない。逆向きの組を確かめるテストを足した。
  - decided_by: AI（2026-10-05 の利用者の指示「FLAGS を 0 にする」による委任）
- A3 FLAG-cli-044 を閉じる。SSH の側だけ参照先がない symlink も、diff は空ファイルと同一扱いせずエラー終了（終了コード 2）にする。IR は変えない。
  - why: コードが SSH の側でも [REQ-cli-022](../../ir/cli/symlink-diff.md#REQ-cli-022) を満たすようになった。SSH の子の一覧の取得が find の終了コードを見ていなかったため、参照先がない symlink が子のないディレクトリとして扱われていた。diff の子の一覧の取得をディレクトリでなければ失敗させ、ローカルの通常ファイルと SSH の参照先がない symlink の組がエラー終了することを確かめるテストを足した。同じ理由で、SSH の側の symlink の参照先が読めないファイルのときもエラー終了になる。
  - decided_by: AI（2026-10-05 の利用者の指示「FLAGS を 0 にする」による委任）
- A4 FLAG-cli-033 を閉じる。include の外のディレクトリを指定した diff の扱いは [A1](#A1) と [REQ-cli-077](../../ir/cli/directory-paths.md#REQ-cli-077) で決まった。
  - why: FLAG-cli-033 は include の外のディレクトリの diff に仕様がないことを記録したもので、利用者がその答えを [A1](#A1) で決め、要件とテストにした。
  - decided_by: 利用者（2026-10-05）
- A5 子がすべて exclude に当たるディレクトリを指定した diff（exclude = ["target"] での `diff target`）がどの経路の組でも差分なし・終了コード 0 になることは、ここでは決めない。exclude に当たるファイルのパスを直接指定した diff が差分を出すことを記録した [FLAG-cli-031](../../ir/cli/FLAGS.md#FLAG-cli-031) に観察として加え、両方を合わせて後で決める。
  - why: 利用者は、どちらも exclude と指定したパスの関係で仕様が定めていない点が同じため、両方を合わせて決めるとした。
  - decided_by: 利用者（2026-10-05）
