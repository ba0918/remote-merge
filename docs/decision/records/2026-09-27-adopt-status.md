# status を kotowari に取り込む際の判断

## Context

status の IR は旧仕様の移行時に 3 要件（[REQ-cli-006](../../ir/cli/status.md#REQ-cli-006)〜[REQ-cli-008](../../ir/cli/status.md#REQ-cli-008)）だけ作られ、比較対象の決め方・判定・出力・三者比較と既存テストの大半が仕分けられていなかった。
旧資料（[旧総合仕様](../../archive/spec.md) の非対話モードと JSON 出力スキーマの節、[旧個別仕様 symlink-merge](../../archive/spec/symlink-merge.md) の 3.8、既存要件と [spec-migration の A21](./2026-09-25-spec-migration.md#A21)）と、入口 `status`（--left、--right、--ref、--format、--summary、--all、--checksum、--max-entries）から見える現行実装・テストを突き合わせ、一致するものは現状を仕様として追認し、食い違い・欠落・曖昧さは FLAG として未決のまま残す。
既存要件 REQ-cli-006〜008 は実装と一致したため変更しない。除外・対象フィルター、走査件数の上限、ディレクトリ symlink の再帰列挙、バックアップ置き場の非表示、エラー時の JSON は他の話題の IR が扱うため、この記録では扱わない。
比較対象の決め方（A1）は diff・merge・sync も同じ仕組みを使う。要件は 14 件で limits.requirements を超えるが、入口は status 一つのため話題は分けず、比較の判定・出力・比較対象と三者比較の 3 文書に責務で分ける。
テストの内訳（対象 149 件）: 要件の根拠 96 件、FLAG の挙動のテスト 11 件、実装詳細をなぞるだけ 7 件、残す 35 件。
