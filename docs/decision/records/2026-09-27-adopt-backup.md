# バックアップと rollback を kotowari に取り込む際の判断

## Context

バックアップと rollback の IR は旧仕様の移行時に 10 要件だけ作られ、旧資料の多くの記述と既存テストの大半が仕分けられていなかった。
旧資料（[旧総合仕様](../../archive/spec.md) のバックアップポリシーと rollback の節、[旧個別仕様 local-backup-store](../../archive/spec/local-backup-store.md)、[旧用語](./legacy-terms.md)）と現行実装・テストを突き合わせ、一致するものは現状を仕様として追認し、食い違い・欠落・曖昧さは FLAG として未決のまま残す。
既存要件 REQ-backup-001〜010 は実装と一致したため変更しない。旧個別仕様 3.12 のファイル単位スキップと同種 symlink の復元非対応は、[A11](./2026-09-25-spec-migration.md#A11) と [A46](./2026-09-25-spec-migration.md#A46) で上書き済みのため FLAG にしない。
旧個別仕様 3.18（エージェントにバックアップ機能を持たせない）・3.20（書き込み先の読み書きの差し替え）・8 章（記録形式）は実装メモとして、[A8](./2026-09-25-spec-migration.md#A8) と [A31](./2026-09-25-spec-migration.md#A31) に従い IR に入れない。
テストの内訳（対象 149 件）: 要件の根拠 129 件、FLAG の挙動のテスト 3 件、実装詳細をなぞるだけ 11 件、残す 6 件。
