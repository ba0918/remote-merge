# CLI diff の差分の出し方を kotowari に取り込む際の判断

## Context

CLI diff の IR は旧仕様の移行時に、ディレクトリ指定の JSON（[REQ-cli-001](../../ir/cli/diff-json.md#REQ-cli-001)）、機密ファイルを隠すこと（[REQ-cli-005](../../ir/cli/safety.md#REQ-cli-005)）、バイナリのハッシュ（[REQ-cli-009](../../ir/cli/binary.md#REQ-cli-009)）、JSON のエラー（[REQ-cli-018](../../ir/cli/results.md#REQ-cli-018)）だけが作られ、出力の形・打ち切り・終了コードと既存テストの大半が仕分けられていなかった。
旧資料（[旧総合仕様](../../archive/spec.md) の LLM エージェント連携・JSON 出力スキーマ・CLI diff での sensitive マスク・バイナリファイルの扱いの節、利用者向けの手引き "skills/remote-merge/SKILL.md" と "skills/remote-merge/references/json-schemas.md" の diff の部分、既存要件）と実装・テストを突き合わせ、一覧を出す前に別の文脈で各行を実装と照らし合わせ、読んで確信の持てない点は試験 SSH サーバに対する実行で確かめた。一致するものは現状を仕様として追認し、食い違い・欠落は FLAG として未決のまま残す。
旧総合仕様の「ディレクトリ指定は --format json では使用不可」は [A15 (旧仕様の移行)](./2026-09-25-spec-migration.md#A15) と REQ-cli-001 で置き換え済みのため FLAG にしない。symlink とディレクトリ symlink は diff の次の回、--ref の参照先と競合はその次の回、TUI の差分表示は凍結中の TUI で扱う。
既存要件 REQ-cli-001・005・018 は実装と一致したため変更せず、REQ-cli-009 は A18 の FLAG を付ける。新しい要件は、バイナリの出し方を既存の文書に足し、残りを新しい文書に置く。
CLI の FLAGS.md はこの回の FLAG で limits.lines の 200 行を超えるが、FLAG は一つの文書に置く決まりで、中身は CLI の一つの責務（コマンドの振る舞いの未決事項）に揃っているため分けない。
テストの内訳（対象 129 件）: 要件の根拠 44 件、FLAG の挙動のテスト 0 件、実装詳細をなぞるだけ 6 件、残す 79 件。
