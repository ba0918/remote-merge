# MSRV を 1.89 にする決定

## Context

MSRV は 1.88 だった（[A3（Rust の版・ツールチェーン・lint の決定）](./2026-10-15-rust-setup.md#A3)）。
SSH ライブラリの russh は 0.63.2 から Rust 1.89 を求め、0.63.2・0.63.3 にはクライアントにも関わる修正が入っている。
MSRV が 1.88 のままだと、Cargo は 1.88 で動く 0.63.1 にとどめる。

Position: 反映済み。

## Agreements

- A1 MSRV を 1.89 にする。workspace の rust-version と CI の MSRV のジョブをそろえて上げる。
  - why: russh 0.63.2 は鍵の再交換をまたいでデータを書くと壊れる不具合（russh #761）を、0.63.3 は書き込みが止まったときにも無通信のタイムアウトを効かせる不具合を直している。どちらも大きなファイルを送るこの CLI の接続に関わる。1.88 で組み立てる利用者は組み立てられなくなるが、配布は組み立て済みのバイナリで、ツールチェーンは 1.99.0 に固定している。
  - decided_by: user (took the recommendation)
