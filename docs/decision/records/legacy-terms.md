# 既存の用語定義の出典

旧 `CONTEXT.md` に記録されていた用語を、IR の用語集に移すための参照元。これらは既存文書の定義であり、機能の実装状況を保証しない。

## バックアップセッション

マージ、sync、rollback、TUI のハンクマージ確定または `w` による 1 回の書き込み操作で取ったバックアップ一式。セッション ID で識別する。TUI を起動してから終了するまでの期間は指さない。

## 書き込み先

バックアップを区別する単位。リモートはホスト名・ポート・root_dir の組、ローカルは root_dir の絶対パス。設定ファイルのサーバ名は表示用であり、同じ名前でも別の書き込み先を指し得る。

## 末尾の symlink

操作対象のパスそのものが symlink である状態。「リーフ」「末端リンク」とは呼ばない。

## 途中の symlink

操作対象の親ディレクトリのうち root_dir より下に symlink がある状態。root_dir 自体が symlink の場合は含めない。「中間リンク」「ディレクトリリンク」とは呼ばない。
