# 旧仕様の移行元

ここには kotowari 導入前の資料を保存する。`spec.md` は構想・操作例・進捗が混在した旧総合仕様、`spec/` の2件は個別にまとめられた旧要件、`CONTEXT.md` は旧用語集。本文に残る旧パスや計画・実装への言及は作成時点の記録であり、現在の仕様や実装状況を保証しない。

正規化した仕様の置き場は `docs/ir/`、判断の出典は `docs/decision/records/` と `docs/decision/adr/`。旧資料から要件を移すときは現行コード・テストと照合し、出典を付けてから `kotowari check` で確認する。
