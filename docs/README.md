# 文書

`docs/` の文書の役割と入口。

| 場所 | 役割 |
|---|---|
| `ir/` | 仕様。振る舞いの正本。要件・表・例を置き、リポジトリのルートで動かす `kotowari check` が根拠テストとの対応を見る。 |
| `decision/records/` | 決定と検討の記録。書いた時点の記録であり、現在の振る舞いの根拠は `ir/` にある。 |
| `archive/` | 上の記録が旧資料として引用する、旧仕様の該当ファイルだけを置く。現在の動作の根拠ではない。 |
| `testing/` | 上の記録が経緯として引用する、テスト整理の記録を置く。現在の動作の根拠ではない。 |
| `remote-tools.md` | 古いリモート環境（CentOS 5、BusyBox、dash など）で使える道具の知識。 |

実装の構造と開発の約束は `../PROJECT.md`、エージェント向けの指示は `../AGENTS.md` にある。
